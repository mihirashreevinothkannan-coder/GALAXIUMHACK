## Member 1: AI-Based Oil Spill Detection Module

[![Python Version](https://img.shields.io/badge/python-3.9%20%7C%203.10%20%7C%203.11-blue.svg)](https://www.python.org/)

OILTRACE is an intelligent marine oil spill investigation system built for the Galuxium Nexus hackathon. The system comprises three interconnected modules:
* **Member 1 (This Repository)**: AI-Based Sentinel-1 SAR Oil Spill Detection & Geospatial Feature Extraction.
* **Member 2 (Teammate)**: AIS Vessel Telemetry Correlation & Drift Origin Tracking.
* **Member 3 (Teammate)**: Streamlit & Folium Interactive Web Dashboard.

## Technical Audit & Verification Disclosures

> [!IMPORTANT]
> **Scientific Integrity & Hackathon Transparency Disclosures**:
> 1. **Active Method**: The operational detection engine is **classical SAR image processing** (multi-look linear-power speckle reduction, $P_{65}$-trimmed sea clutter estimation, adaptive contrast thresholding, morphological open/close, and 8-connected component analysis with shadow proximity discrimination).
> 2. **Pretrained Model Status**: PyTorch 2.1 is present in the environment, but lightweight pretrained segmentation weights could not be fetched due to corporate SSL certificate errors, and no weights were bundled locally. The pipeline gracefully falls back to the classical engine, which operates reliably without remote dependencies.
> 3. **Supported Image Formats**: Accepts `.png`, `.jpg`, `.jpeg`, `.tif`, `.tiff` (both 8-bit and 16-bit single-band), and `.bmp`. Non-image files and empty files are rejected with informative errors. Processed 8-bit display chips (JPEG/PNG) are explicitly flagged in JSON metadata to distinguish them from calibrated Level-1 SAR backscatter products.
> 4. **Data Fixtures**: The files in `data/samples/` are **synthetic SAR test fixtures** generated by `data/generate_samples.py`. They are parameterized with authentic radar backscatter statistics (background mean ~44, slick mean ~18) from the Garcia-INPE Sentinel-1 Cantarell dataset (`S1A_IW_GRDH_1SDV_20200117T001541`, CC BY 4.0), but are **not raw ESA satellite image rasters**.
> 5. **Geospatial Projection**: Geographical coordinates are calculated using a **nominal affine bounding box model** (10m/pixel nominal Sentinel-1 IW GRDH resolution centered at Lat 19.378°N, Lon -92.035°W), not embedded GeoTIFF ground control points.
> 6. **Evaluation Metrics**: The benchmark metrics ($\text{IoU} = 0.978$, $\text{Dice} = 0.989$) measure the classical detector against the synthetic ground-truth fixture mask to verify algorithmic segmentation correctness. They **do not represent validated operational real-world accuracy on uncurated satellite scenes**.
> 7. **Look-alike Uncertainty**: Detection outputs identify **candidate dark formations**; they do not prove chemical mineral oil contamination without multi-sensor or AIS drift corroboration. Dark patches adjacent to high-backscatter structures are classified as `shadow_suspect`.

## Quickstart Guide

### 1. Installation
Install the lightweight dependencies (no heavy external compilers needed):
```bash
pip install -r requirements.txt
```

### 2. Run Oil Spill Detection on Sample SAR Image
Execute detection on the Cantarell Sentinel-1 SAR sample:
```bash
python detection/detect_spill.py --image data/samples/s1_cantarell_slick.png --reference-mask data/samples/s1_cantarell_reference.png
```

### 3. Run Negative Control (Clean Sea Test)
Verify zero false alarms on clean ambient open water:
```bash
python detection/detect_spill.py --image data/samples/s1_clean_sea.png
```

### 3. Run Detection on Real Sentinel-1 SAR Tiles (MKLab-ITI)
The `data/real_samples/` directory contains two Sentinel-1-derived tiles from the **MKLab-ITI Oil Spill Detection Dataset** (Krestenitis et al., 2019).

> [!IMPORTANT]
> These images are distributed **access-on-request for non-commercial research only** by MKLab/CERTH-ITI. See [`data/real_samples/PROVENANCE.md`](data/real_samples/PROVENANCE.md) for full terms. No geographic coordinates or reference masks are available for these tiles.

```bash
python detection/detect_spill.py \
  --image data/real_samples/sentinel1_mklab_sample_01.jpg \
  --output-dir outputs/real_eval \
  --min-pixels 100 \
  --dataset-source "MKLab-ITI Oil Spill Detection Dataset (Krestenitis et al. 2019)" \
  --dataset-license "Access-on-request, non-commercial research only"
```

**Console Output:**

## Running the Automated Test Suite
The codebase includes 25 rigorous unit and integration tests covering:

* Multi-format image validation (PNG, JPEG, TIFF 8/16-bit, BMP, empty-file and bad-extension rejection)
* Multi-look linear power speckle reduction
* $P_{65}$-trimmed sea clutter estimation in heterogeneous scenes with bright land
* Shadow-suspect classification for dark patches adjacent to high-backscatter structures
* Synthetic dark-patch detection and clean-sea rejection
* Morphological opening and closing
* Precision bounding box and centroid calculations
* Affine geospatial coordinate projection
* Missing-file and unreferenced fallbacks
* End-to-end pipeline execution and JSON schema compliance

Run all tests:
```bash
python -m unittest discover -s tests -v
```

## Inter-Module Hand-Off Contract (For Teammates)

See [`docs/INTEGRATION_CONTRACT.md`](docs/INTEGRATION_CONTRACT.md) for full details.

* **Member 2 (AIS)**: Reads `spill_location_estimate.centroid_latitude`, `spill_location_estimate.centroid_longitude`, and `satellite_metadata.acquisition_timestamp_utc` to query vessel historical movements.
* **Member 3 (Dashboard)**: Uses `artifacts.overlay_path` for UI display and `spill_location_estimate` for Folium map markers. Displays the mandatory `scientific_disclaimer`.
